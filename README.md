# Reflection
Over the course of this series of projects, I have gradually increased my knowledge of Machine Learning algorithms and learned how to build and train my own models. I start with a simple regression model in the first project, and also learn about the importances and how to preprocess data before using it to create a model. I also create graphs and learn how to visualize my models and their outcomes from this model. I then move on to binary classification in the second project using different model designs like the regression model, the k- nearest neighbor and the random forest method. In the next project, I use the support vector machine model to come up with a classification model. I use the RBF and the Poly kernel methods to increase the accuracy of the models when it comes to their classification predictions too. In the next project, I then used decision trees to make a classification model. I also visualized the trees and used them to figure out which parameters were the most important ones when it came to classifying the different items. The next project was about dimensionality reduction, where I learned how to take databases with tons of dimensions and reduce them to the minimum number of dmiensions without losing much accuracy in order to make my model better and more accurate at making predictions. The las two projects dove into neural networks. In the first one, I look at artificial neural networks and design a model that can be used to predict what article of clothing a picture represents based off of a training set of other similar images. Lastly, I work on a project that uses natural language processing. In this model, my model is used to determine the sentiment in a statement. It groups them as either positive or negative based on the nature of the language. The model was a neural network that had been optimized for language processing. Overall, I feel like each project used aspects from the previous ones and built on them while also introducing new concepts. This helped reinforce my understanding of the older concepts while also learning more about the new topics being introduced. I gained a lot of understanding of how machine learning models work and plan to continue designing more and finding new applications for the machine learning models I have learnt about!
